# Survey Atlas · 巡天数据图集

**选巡天数据之前的案头图集。** 59 个主流天文巡天，每个一份档案：发布了什么数据、什么形态、覆盖多大天区、能测到多暗、以什么节奏观测、去哪里下载。

**在线使用 → https://jianxing-chen.github.io/survey-atlas/**

数据逐条核实至 **2026-10-08**（Gaia DR4 预计 2026-12；DESI 公开版为 DR1；Rubin DP2 已发布；Legacy DR11、LAMOST DR13、COSMOS-Web DR1、VVVX 最终版……均经官方渠道核对）。

---

## 它解决什么问题

天文学的数据不是不够，而是**太难选**。选题的时候，你需要回答一连串问题：这个巡天是测光还是光谱？覆盖南天还是北天？深度够不够我的目标？最新的 DR 是哪一版、下一版什么时候出？数据在哪个档案库、要不要申请？

这些问题分散在几十个官方网站、发布论文和文档页里，口径各异、更新频繁。Survey Atlas 把它们整理成一本可以逐页翻的图集，让你在动手下载数据之前，先用几分钟把选项看全。

三个典型场景：

- **选题** ——「我想做这类科学，有哪些数据可用？」→ 从[选型指南](https://jianxing-chen.github.io/survey-atlas/#guide)的 11 类科学问题反查推荐数据集；
- **动手前** ——「这个巡天到底发布了什么、去哪下？」→ 在总表点开它的档案卡，产品形态、规模、获取方式一页读完；
- **排期** ——「最近发了什么、未来半年还有什么在路上？」→ 看[发布日历](https://jianxing-chen.github.io/survey-atlas/#timeline)的双轨时间线，别让提案撞上还没发布的数据。

## 怎么用

- **按波段浏览**：首页的频谱导航尺按真实电磁频谱排列（射电 → 红外 → 光学 → 紫外 → X 射线），点一下即筛选总表；光谱、时域、天测等跨波段方法在下方单独一行。
- **对比总表**：59 行 × 11 列，全部列可排序（数值列 N/A 恒沉底），支持中英文搜索（名称 / 望远镜 / 波段），按 <kbd>/</kbd> 快速聚焦搜索框。
- **档案卡**：点击任意一行打开——巡天计划（这是什么项目、观测几年、设计天区与节奏）/ 发布了什么数据 / 形态与规模 / 观测节奏 / 怎么获取 / 适合做什么。<kbd>←</kbd> <kbd>→</kbd> 在巡天之间翻页，<kbd>Esc</kbd> 关闭，每张卡都有直达官方档案的链接与深链 URL（`#d-巡天id`），可以直接引用给合作者。
- **面积 × 深度图**：成像与光谱两张散点图，一眼看出谁「又深又广」。
- **口径诚实**：数值带 `≈` 为约值、带 `⚠` 为未能二次核实项；Vega/AB 星等系统、5σ/10σ 口径差异在来源一节如实标注。

## 覆盖范围

9 个波段/方法域：光学成像、红外成像、紫外、河外光谱、银河系光谱、射电、X 射线、时域、天测——从 SDSS、2MASS 这样的经典档案，到 DESI、Euclid、Rubin/LSST、SPHEREx、CSST 等正在进行的巡天，含未来 18 个月的关键发布节点。

## 数据从哪里来、有多可信

所有条目汇总自各巡天**官方发布渠道**（官网、官方文档、发布论文），关键时效信息（最新 DR、下一版日期、公开状态）逐条核实，并在页面标注核实日期。巡天的发布计划经常变动，本页为人工整理难免滞后——**引用具体数值前，请点击页面内链接到官方页面复核**。

发现错误或缺漏？欢迎提 [Issue](https://github.com/jianxing-chen/survey-atlas/issues) 或 PR（请附官方来源链接）。

## 维护数据

所有内容集中在 [`data.js`](data.js) 一个文件：按既有字段增删 `SURVEYS` 条目即可，渲染逻辑无需改动。`areaN / depthN / nN / rN` 为排序用数值键。

## 技术形态

纯静态页面：`index.html + style.css + data.js + app.js`，零依赖、零构建、无追踪，双击 `index.html` 即可离线使用。配色、字体、频谱导航尺等设计决策集中在 `style.css` 顶部的 token 区。

部署：任意静态托管均可；GitHub Pages 路径为仓库 Settings → Pages。
